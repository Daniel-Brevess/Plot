Resumo atual

O Plot ja possui uma base demonstravel: autenticacao, questionario de generos, recomendacoes por API, navegacao principal, perfil editavel, APK Android atualizado e login Google nativo configurado para Android. A maior parte das pendencias vem de recursos anunciados nos slides antes de serem implementados.

  • Aplicativo Ionic e Angular estruturado e compilando.
  • APK Android atualizado em apk/app-debug.apk.
  • Suite automatizada executando com 9 testes aprovados.
  • Login Google Android configurado com Web Client ID, google-services.json atualizado e SHA-1 debug registrado no Firebase.
  • Corrigir os 12 erros restantes do lint.
  • Alinhar README e slides com o escopo realmente entregue.

Requisitos funcionais

Autenticacao e conta

  • Cadastro de usuario com nome, e-mail e senha.
  • Login com e-mail e senha.
  • Login com conta Google.
    • Fluxo implementado para navegador com Firebase.
    • Fluxo nativo Android implementado com Credential Manager e troca do ID token por credencial Firebase.
    • SHA-1 debug identificado: 32:F6:BA:1C:24:92:A1:7A:1A:03:12:FE:71:46:D7:70:0D:D2:BC:73.
    • Web Client ID configurado em environment.googleWebClientId.
    • Arquivo android/app/google-services.json atualizado apos o cadastro do SHA-1 no Firebase.
    • Fluxo validado em aparelho Android com Google Play Services.
  • Manutencao de sessao e redirecionamento automatico de usuario autenticado.
  • Logout do sistema.
    • Metodo de logout criado no servico de autenticacao.
    • Botao de sair adicionado na interface com redirecionamento para a tela inicial.
  • Recuperacao de senha por e-mail.
  • Protecao de rotas para impedir acesso direto ao feed, explorar, perfil, edicao de perfil e questionario sem login.

Preferencias e recomendacoes

  • Questionario com selecao de exatamente tres generos literarios.
  • Persistencia das preferencias do usuario no Firestore.
  • Feed personalizado com livros carregados conforme os generos escolhidos.
  • Consumo da API gratuita Open Library.
  • Exibicao de titulo, autor e capa quando fornecidos pela API.
  • Imagem padrao local exibida quando a API nao retorna capa.
  • Genero "Classicos" mapeado para o assunto classic_literature da Open Library.
  • Exibicao de sinopse real dos livros quando a informacao esta disponivel na Open Library.
  • Exibicao de avaliacoes reais da Open Library quando ha votos, com indicador honesto quando nao ha avaliacoes.
  • Busca de livros por texto na pagina Explorar.
  • Carregamento progressivo para listas maiores de livros.
  • Tratamento visual para livros sem capa, autor ou sinopse.

Navegacao e exploracao

  • Navegacao entre feed, explorar e perfil.
  • Pagina Explorar registrada nas rotas e carregando livros da API.
  • Pagina Explorar.
    • Lista inicial funcional usando livros de romance.
    • Busca por texto e genero implementada.
    • Estados visuais para carregamento, nenhum resultado e erro de busca.

Perfil

  • Perfil exibindo nome e e-mail do usuario autenticado.
  • Edicao do nome persistida no Firebase Authentication e no Firestore.
  • Selecao de foto salva localmente por usuario no aparelho.
  • E-mail da conta definido como nao editavel pelo perfil.
  • Favoritos reais exibidos no perfil a partir do Firestore.

Favoritos e avaliacoes

  • Botao para favoritar e desfavoritar livros no Feed, Explorar e Detalhe do Livro.
  • Favoritos persistidos individualmente por usuario no Firestore.
  • Listagem e remocao de favoritos reais no perfil.
  • Avaliacoes agregadas exibidas a partir da Open Library.

Armazenamento e recursos nativos

  • Firebase Authentication configurado.
  • Firestore usado para preferencias, favoritos e dados basicos do perfil.
  • Configuracao Android do Firebase incluida em android/app/google-services.json.
  • Uso simples de armazenamento local para a foto do perfil.
  • Ionic Storage, Preferences e SQLite citados no slide nao estao implementados. Implementar somente se forem realmente necessarios ou remover do slide.
  • Filesystem com arquivos CSV e JSON citado no slide nao esta implementado. Implementar ou remover do slide.
  • Criar e incluir o modelo ER anunciado no slide, caso ele faca parte da entrega.
  • Vibracao com Capacitor Haptics.
    • Plugin instalado no projeto.
    • Usar o plugin em alguma interacao ou remover a afirmacao de uso.
  • Camera citada no slide nao esta instalada nem utilizada. Implementar ou apresentar como trabalho futuro.
