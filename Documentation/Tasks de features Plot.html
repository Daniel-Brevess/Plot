Tasks de features do projeto Plot

Lista focada apenas em funcionalidades do aplicativo

Atualizado em 4 de junho de 2026
Projeto academico de Analise e Desenvolvimento de Sistemas

Escopo deste documento

Este PDF lista somente tarefas relacionadas a funcionalidades percebidas pelo usuario.

Nao inclui pendencias tecnicas como lint, build, versao do Node, testes automatizados, identificadores nativos ou configuracoes internas.

Prioridades sugeridas

  • AltaFeature importante para demonstracao, fluxo principal ou requisito anunciado.
  • MediaFeature relevante para completar a experiencia, mas que pode entrar depois da demonstracao principal.
  • BaixaMelhoria desejavel ou item que pode ser apresentado como trabalho futuro.

Recomendacoes e livros

  • AltaImplementar busca de livros por texto.
  • AltaExibir sinopse real dos livros quando a informacao estiver disponivel.
  • MediaImplementar carregamento progressivo para listas maiores de livros.
  • MediaMelhorar a experiencia quando um livro nao tiver capa, autor ou sinopse.

Explorar

  • AltaTransformar a pagina Explorar em uma area realmente exploratoria, com filtros ou escolha de genero.
  • AltaPermitir combinar busca por texto com genero literario.
  • MediaAdicionar estados visuais para carregamento, nenhum resultado e erro de busca.

Favoritos

  • AltaImplementar botao para favoritar e desfavoritar livros.
  • AltaSalvar favoritos individualmente por usuario.
  • AltaListar os favoritos reais no perfil.
  • MediaPermitir remover favoritos diretamente pela tela de perfil.

Avaliacoes

  • AltaDecidir se as avaliacoes serao removidas da apresentacao ou implementadas como feature real.
  • MediaSe a feature for mantida, definir se a nota vira de uma fonte externa ou dos proprios usuarios do app.
  • MediaSubstituir estrelas decorativas por avaliacoes reais ou por outro indicador honesto.

Perfil

  • AltaSubstituir os favoritos fixos exibidos no perfil por dados reais.
  • MediaPermitir atualizar a foto do perfil usando uma imagem escolhida pelo usuario.
  • BaixaAvaliar se vale incluir captura de foto diretamente pelo app.

Preferencias

  • MediaPermitir que o usuario edite os tres generos preferidos depois do cadastro inicial.
  • MediaAtualizar o feed automaticamente quando as preferencias forem alteradas.
  • BaixaAdicionar uma explicacao curta para o usuario entender como as recomendacoes sao formadas.

Experiencia do usuario

  • MediaAdicionar mensagens claras para falhas de login, cadastro, busca e carregamento de livros.
  • MediaRevisar a tela "Sobre o Plot" para prometer somente funcionalidades existentes ou planejadas como futuro.
  • BaixaAdicionar feedback discreto em interacoes importantes, como favoritar livro ou salvar perfil.

Ordem recomendada

  1. Implementar busca de livros.
  2. Implementar favoritos reais e exibir no perfil.
  3. Decidir e ajustar avaliacoes.
  4. Melhorar a pagina Explorar com filtros e generos.
  5. Permitir edicao de preferencias literarias.
